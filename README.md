# Site anniversaire GitHub Pages

Mini site statique en 3 étapes, compatible avec GitHub Pages :

1. `index.html` : page de login
2. `challenge.html` : formulaire de validation
3. `birthday.html` : page finale de félicitations

## Démonstration

Identifiants de la première page :

- Login : `rayane`
- Mot de passe : `lemeilleur`

Réponse attendue sur la deuxième page : `le plus intelligent`

## Déploiement

Dépose simplement le projet sur GitHub Pages. Aucun build ni dépendance n'est requis.
